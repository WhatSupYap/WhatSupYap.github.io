## 1. 성장과정 및 지원동기

저는 2011년부터 13년간 C#과 ASP.NET 기반의 백엔드 개발자로 일해왔습니다. Deloitte 안진회계법인, 포스코건설, 롯데, SK C&C 등 대형 고객사를 대상으로 EAI 구축, 웹 시스템 개발, 대규모 서버 마이그레이션을 수행하며 "안정적이고 견고한 시스템"을 만드는 일에 자부심을 가졌습니다.

전환점은 팬데믹 시기에 찾아왔습니다. 게임 자동화 스크립트가 인간보다 정밀하게 동작하는 것을 목격하며, 단순 반복을 넘어 스스로 판단하고 최적화하는 **지능형 자동화**야말로 다음 시대의 엔지니어링이라는 확신을 갖게 됐습니다. 안정적인 시니어 자리를 뒤로하고 **1,000시간의 AI 몰입 교육(SKNetworks AI Camp)**을 선택한 것도 그 확신에서 비롯된 결정이었습니다.

귀사에 지원하는 이유는, 13년간 쌓아온 대규모 엔터프라이즈 시스템 설계 경험과 최신 AI·MLOps 역량을 결합하여 실질적인 비즈니스 임팩트를 만들어낼 수 있는 환경이라고 판단했기 때문입니다.

## 2. 직무 역량 및 주요 성과

**[AI & MLOps 역량]**

최종 프로젝트인 **AJC(AI 기반 적응형 문서 생성 시스템)**에서는 Gemma-2-9B 모델을 파인튜닝하고 2B 모델로 지식 증류(Knowledge Distillation)하여 운영 비용을 절감했습니다. GitHub 등에서 123MB의 IT 문서를 수집·정제하고 6,000개의 학습 쌍을 구성하는 **데이터 엔지니어링** 전 과정을 주도했습니다. 또한 FastAPI를 활용해 일반 API 서버와 AI 추론 전용 서버를 분리(Decoupling)하여, 무거운 sLLM 추론 부하가 메인 서버에 영향을 주지 않는 안정적인 서빙 아키텍처를 설계했습니다.

**ZIPFIT(공공주택 AI 에이전트)** 프로젝트에서는 LangGraph 상태 머신으로 5가지 사용자 의도를 분류하고, 기존 4~5회 낭비되던 LLM API 호출을 1회로 압축해 응답 지연 시간과 비용을 대폭 절감했습니다.

**[엔터프라이즈 백엔드 역량]**

13년간 27개 이상의 프로젝트를 수행하며 MS-SQL, Oracle, PostgreSQL 등 다양한 데이터베이스에 대한 전문성과, Windows Server 2003부터 Azure 클라우드까지 이어지는 인프라 운영 경험을 보유하고 있습니다. ASP.NET Core 8 기반의 최신 아키텍처도 실무에서 적용한 경험이 있습니다.

## 3. 입사 후 포부

입사 후 단기적으로는, 팀의 코드베이스와 서비스 아키텍처를 빠르게 파악하고 즉시 기여할 수 있는 포지션을 찾겠습니다. 13년의 실무 경험 덕분에 새로운 환경에 대한 적응 속도는 자신 있습니다.

중장기적으로는 제가 설계하고 구현한 **AI 자동화 파이프라인**이 팀의 반복 업무를 줄이고 개발 생산성을 높이는 방향으로 기여하고 싶습니다. 데이터 수집부터 모델 서빙, 모니터링까지 이어지는 MLOps 사이클 전체를 자동화하는 것이 목표입니다.

## 4. 성격의 장단점 및 협업 역량

**장점**: 2012년부터 이어온 14년의 스윙댄스 경험은 저에게 기술적 역량 이상의 것을 가르쳐주었습니다. 파트너와 박자를 맞추고 상대의 움직임을 배려하는 과정이 곧 협업의 본질과 같다는 것입니다.

AI 부트캠프 최종 프로젝트에서 기술적 난관과 촉박한 마감으로 팀 내 갈등이 깊어져 프로젝트 무산 위기에 처했을 때, 저는 코드 대신 **대화로 간극을 좁혔습니다**. 시니어로서 다져온 침착함과 댄스로 배운 유연함을 바탕으로 팀원 모두가 만족하는 방향으로 프로젝트를 완주했습니다. "기술은 도구가 만들지만, 성과는 사람이 만든다"는 신념을 지금도 간직하고 있습니다.

**단점**: 완성도에 대한 높은 기준으로 인해 때로는 작업에 많은 시간을 할애하는 경향이 있습니다. 이를 개선하기 위해 작업 단위를 명확히 정의하고, 완료 기준(Definition of Done)을 사전에 합의하는 방식으로 일하는 습관을 들이고 있습니다.
