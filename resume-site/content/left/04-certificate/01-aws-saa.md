# AWS Certified Solutions Architect - Associate
**Amazon Web Services (AWS)**
*2024.03*

### 자격 내용
- **자격명**: AWS Certified Solutions Architect – Associate (SAA-C03)
- **발급기관**: Amazon Web Services (AWS)
- **내용**: AWS 기술을 사용하여 안전하고 강력한 애플리케이션을 설계 및 배포하는 지식을 검증.
- **주요 영역**:
    - 보안 아키텍처 설계
    - 탄력적인 아키텍처 설계
    - 고성능 아키텍처 설계
    - 비용 최적화 아키텍처 설계
