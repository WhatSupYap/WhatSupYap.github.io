# 도쿄 숙소 가격 예측 프로젝트

> **합리적인 도쿄 여행을 위하여**  
> 숙소의 옵션(어메니티)과 위치 정보를 바탕으로 적정 가격을 예측합니다.

## 핵심 성과
- **비정형 데이터 처리**: `amenities` 컬럼의 복잡한 문자열 배열 데이터를 **AST** 라이브러리로 파싱하여 정형 데이터화했습니다.
- **가격 모델링**: LightGBM 회귀 모델을 통해 데이터 기반 가격 예측을 구현했습니다.
- **웹 서비스**: Streamlit으로 사용자가 조건을 입력하면 예상 가격을 보여주는 간편한 UI를 제공했습니다.

## 나의 역할
- **데이터 전처리 난제 해결**: 텍스트로 저장된 배열 데이터를 Python의 `ast` 라이브러리로 구조화하는 방법을 제안하고 구현했습니다.
- **카테고리화**: 100개가 넘는 어메니티 항목을 유의미한 30개 카테고리로 분류하여 모델 학습 효율을 높였습니다.

## 기술 스택
- **Language**: Python
- **Lib**: AST, Pandas, Scikit-learn, LightGBM
- **UI**: Streamlit
