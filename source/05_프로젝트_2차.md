## 프로젝트 개요

### 배경
- 스트리밍 서비스 경쟁 심화
- 구독 기반 서비스에서 이탈률 감소는 수익과 직결
- 고객 이탈 최소화 필요

### 목표
1. 넷플릭스 유저 데이터 기반의 이탈 예측 모델 개발
2. 데이터 전처리 및 피처 엔지니어링
3. 시각화를 통한 인사이트 제공
4. 의사결정 지원

---

## 나의 역할

### EDA 및 데이터 전처리
- 데이터 구조 파악
- 결측치 및 이상치 처리
- 숫자형/범주형 컬럼 변환

### 피처 엔지니어링
- 범주화 작업 (연령, 소득, 시청 시간)
- 지역별 구독료 데이터 결합
- 파생 변수 생성:
  - User_Subscription_Price
  - Price_Burden_Ratio (소득 대비 부담률)
  - Watch_Time_per_Dollar
  - Satisfaction_per_Dollar
  - Queries_per_Month

### 모델링 및 평가
- LightGBM 모델 학습
- 하이퍼파라미터 튜닝
- 모델 평가

## 인사이트

### 이탈 위험 고객 특성
1. **연령대**: 특정 연령대에서 이탈률 높음
2. **프로모션 사용**: 쿠폰 사용 횟수와 이탈 관련성
3. **고객 문의**: 문의 수가 많을수록 이탈 가능성 증가
4. **요금 부담**: 소득 대비 구독료 비율이 높으면 이탈 증가
