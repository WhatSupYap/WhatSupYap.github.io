## Trouble Shooting

### 문제
`amenities` 컬럼이 호스트가 직접 입력한 배열 형태의 문자열로 구성되어 학습용 데이터로 사용하기 어려웠다.

### 해결
1. 모든 데이터를 다운로드하여 패턴 분석
2. AST 라이브러리를 사용하여 텍스트 분류
3. 약 30종류로 카테고리 분류
4. 분류된 데이터를 ML 학습에 활용

### 배운 점
- 데이터 탐색의 중요성
- 라이브러리 활용 능력
- 비정형 데이터 처리 경험
