## 프로젝트 개요

### 핵심 아이디어
sLLM 기술을 활용해 문서들의 내용을 분석하며 자동으로 문서들을 병합 및 최신화. 한 곳의 문서에서 수정이 됐을 시, 같은 내용을 포함하고 있는 문서에도 자동으로 수정사항이 적용.

### 문제 정의
1. **지식 관리 난이도**: 산발적으로 흩어진 지식 정보의 동기성 유지 어려움
2. **문서 보안 이슈**: LLM 사용 시 중요 문서 내용 유출 우려
3. **고비용**: 매번 LLM 사용은 비효율적

### 프로젝트 목표
- 문서 작업의 간편화와 효율화
- 지식 관리 자동화
- 민감정보 암호화 및 문서 보안

## 기술 스택

### 프론트엔드
- Next.js (TypeScript)

### 백엔드
- **API Server**: FastAPI
- **AI Server**: Python (별도 마이크로서비스)
- **DB**: PostgreSQL

### AI/ML
- **Teacher Model**: Google Gemma-2-9B-IT
- **Student Model**: 2B (지식 증류)
- **임베딩 모델**: Semantic 청크용, RAG용
- **기법**:
  - Knowledge Distillation (지식 증류)
  - RAG (Retrieval Augmented Generation)
  - Fine-tuning
  - Semantic Chunking

### 인프라
- AWS 클라우드

## 데이터 처리

### 데이터 수집
- **출처**: 자체 생성 + GitHub 오픈소스 문서
- **대상**: IT 용어가 포함된 주제별 문서
- **수집 기간**: 2025.12.20 ~ 2025.12.24
- **크기**: 123MB

### 데이터 전처리
1. **민감 정보 마스킹**: HTML, 이름, 숫자 등 대체
2. **요약 생성**: OpenAI API 활용
3. **최종 데이터**: 6,000개 문장 쌍 (긴 문장 - 요약)

### 모델 학습

#### 요약 모델 (Student)
- **Teacher**: Google Gemma-2-9B-IT
- **기법**: Knowledge Distillation (지식 증류)
- **결과**: 2B Student 모델 생성

#### 임베딩 모델
- **데이터**: 2,000개 Positive-Negative 쌍
- **Base 모델**: Google Gemma-2-9B-IT
- **학습**: Metric Learning
