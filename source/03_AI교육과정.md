## 주요 학습 내용

### 기초 과정
- Python 프로그래밍
- 데이터베이스 설계 및 쿼리
- 리눅스 환경 설정

### 데이터 과정
- 웹 크롤링 기법
- 데이터 분석 및 시각화
- EDA (탐색적 데이터 분석)

### ML/DL 과정
- 머신러닝 알고리즘
- 딥러닝 아키텍처
- 모델 평가 및 최적화

### NLP/LLM 과정
- 자연어 처리 기초
- Transformer 아키텍처
- LLM 활용 및 파인튜닝
- 프롬프트 엔지니어링
- RAG (Retrieval Augmented Generation)

### 멀티모달
- 텍스트-이미지 결합 모델
- CLIP, Stable Diffusion 등

### 웹 개발
- Django 백엔드 개발
- 화면 구현
- RESTful API

### 인프라
- 클라우드 서비스 (AWS, Azure)
- 배포 및 운영
